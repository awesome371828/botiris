# GDE.WTF_MODER_API.md

## Назначение

Интеграция Pear CM с отдельным внешним API управления командой модераторов GDE.WTF. Она обращается только к API `https://map.gde.wtf/api/ext` и не меняет внутреннюю базу Pear CM.

## Безопасность и конфигурация

Задайте на хосте следующие переменные окружения:

- `GDEWTF_API_KEY` — действующий ключ внешнего API.
- `BOT_OWNER_ID` — Telegram ID владельца Pear CM; команды интеграции доступны только этому аккаунту.
- `GDEWTF_API_BASE` — необязательно; по умолчанию `https://map.gde.wtf/api/ext`.

Ключ не хранится в исходном коде и не должен попадать в Git. Он передаётся API в заголовке `Authorization: Bearer …`. HTTP-клиент имеет тайм-аут 8 секунд, чтобы недоступность внешнего сервиса не подвешивала обработчик надолго.

**Важно:** ключ, опубликованный в сообщении при настройке, следует считать раскрытым. Отзовите/замените его в конфигурации GDE.WTF (`auth_config.json`, поле `ext_api_key`), перезапустите сервис и сохраните новый ключ только в секретных переменных хоста как `GDEWTF_API_KEY`. Не добавляйте его в этот документ или репозиторий.

## Команды Pear CM

Все команды начинаются с `gde` (также принимаются `/gde`, `!gde`, `gdewtf`) и выполняются только владельцем Pear CM.

| Команда | Действие |
| --- | --- |
| `gde help` | Показать справку |
| `gde ping` | Проверить ключ и доступность API |
| `gde профиль <q>` | Показать профиль модератора |
| `gde модераторы [city_id]` | Список модераторов, опционально по городу |
| `gde города` | Список городов и их ID |
| `gde журнал [q] [limit]` | Журнал действий; limit ограничивается диапазоном 1–200 |
| `gde варн <q> <причина>` | Выдать предупреждение |
| `gde снятьварны <q> [index]` | Снять одно предупреждение по индексу с нуля или все предупреждения |
| `gde ник <q> <ник>` | Назначить ник; `-` снимает ник |
| `gde город <q> <city_id>` | Назначить/сменить город; `-` убирает город |
| `gde амб <q>` | Назначить амбассадором города |
| `gde rgov <q> <region> [city1,city2]` | Назначить региональным управляющим с регионом и необязательным списком городов |
| `gde назначить <q> [city_id] [права]` | Назначить/обновить модератора |
| `gde снять <q>` | Снять с модерации |
| `gde бан <q> [причина]` | Забанить аккаунт |
| `gde разбан <q>` | Разбанить аккаунт |

В поле `q` можно указывать pub-код (например, `RND-AB3K`), `@username` или Telegram ID.

## Поддерживаемые методы API

Интеграция использует:
- `GET /ping`, `GET /mod?q=…`, `GET /mods`, `GET /cities`, `GET /log`
- `POST /warn`, `POST /warn/clear`, `POST /nick`, `POST /city`
- `POST /mod/set`, `POST /mod/remove`, `POST /ban`

Ожидается JSON-ответ API с полем `ok`. Известные ошибки API преобразуются в читаемые сообщения; сетевые ошибки и тайм-ауты не выводят секретный ключ в чат или логи.

## Установка на Relax Dev

1. В настройках проекта добавьте секретную переменную `GDEWTF_API_KEY` с новым, заменённым ключом.
2. Убедитесь, что `BOT_OWNER_ID` задан корректно.
3. Перезапустите Pear CM, чтобы он загрузил новые переменные и модуль `gdewtf_moder_api.py`.
4. В личном чате с ботом отправьте `gde ping`, затем `gde help`.

Если ключ не задан, бот сообщит об этом без выполнения запроса. Интеграция не меняет права Telegram-групп и не заменяет встроенные команды модерации Pear CM.

Три шага

начало работы
1
Войди через Telegram или MAX

На сайте откроется бот подтверждения. Сервис указывает, что для входа требуется номер российского формата +7 9xx; ознакомься с политикой конфиденциальности перед передачей данных.

2
Выбери город и смотри карту

Проверь верхнюю строку статуса, метки и активность по районам. Можно переключать лайв и историю.

3
Сообщи, если слышишь событие

Через кнопку сообщения на карте поставь метку по геопозиции. Подтверждение помогает снизить влияние одиночных ложных отметок.
